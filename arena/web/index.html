  3. 계약 검증질문·형식·지문
  4. 독립 정책모델과 분리된 규칙

어떻게 작동하나요?
  1. 입력 — 지금 입력한 문장만 모델로 보냅니다. 원문은 저장하지 않습니다.
  2. Zoro-1 제안 — 모델이 요청 행동·화행 같은 질문에 확률로 답합니다. 이 확률은 사기 확률이 아닙니다.
  3. 계약 검증 — 질문 목록, 응답 형식, 계약 지문이 맞지 않으면 판단하지 않고 사람 확인으로 넘깁니다.
  4. 독립 정책 — 모델과 분리된 규칙이 원문 단서와 함께 안내를 정합니다. 앞서 감지한 위험은 다음 문장이 평범해도 유지됩니다.
  5. 확인 업무 — 송금·문자 발송 같은 실제 행동은 하지 않고, 공식 경로로 확인할 일만 남깁니다.
