# IteraGuard — 의심계(Doubt Meter): 심사위원 시연 설명서

2026 TRILLION AGENT AI HACKATHON · Track 1 / Zoro-1 Arena · 합성 입력 검증형 데모

## 제품 한 문장

**의심계는 통화나 메시지 속 위험한 행동 요청을 검토하고, 실제 이체나 인증정보 제공을 하기 전에 멈춰서 독립된 공식 경로에서 확인하도록 돕는 개입 에이전트다.**

## 시연 순서 (약 3분 목표, 실제 시간 실측 전)

1. **정상 금융 안내**: 통화 상대가 예금 만기 조회를 공식 앱이나 지점에서 확인하도록 안내. 위험 행동 요청 부재 → `NO_STRONG_SIGNAL`. 화면은 “안전 보증이 아님”을 명시.
2. **송금 압박**: 수사기관을 사칭한다고 주장하는 합성 대본에서 직접 송금 요청이 나타남 → 정확 인용구간 검증 → `PAUSE_AND_VERIFY`. 실제 송금을 막거나 계좌를 동결하지 않음.
3. **인용·반례**: '송금하세요라는 요구에 응하지 마세요'가 등장함 → 위험어휘만으로 고위험 판정하지 않음.
4. **모호한 주장/모델 실패**: 근거 부족/오류 시 `ASK_HUMAN`으로 안전하게 보류.
5. **확인 계획 기록**: 실제 공식 기관의 확인 완료가 아닌 의도만 기록함을 UI에서 확인. 다음 턴에 위험 요청이 없다면 버전이 증가한 새로운 판단을 표기.

## 기술 설명용 패널

- 모델 후보·정책 권한 분리: Zoro-1 Typed Decision 계약은 별도 스모크 테스트로 확인해야 하는 외부 의존성.
- 근거 기반 온톨로지: `REQUESTS` vs `REPORTS` vs `WARNS_AGAINST` vs `AMBIGUOUSLY_MENTIONS`.
- 안전 정책: 4개 비파괴적 안내 상태, 비정상 입력의 보류.
- 결과 추적: 세션 버전과 멱등성, 로컬 무서명 감사 해시 체인.
- 증거 분리: 합성 시나리오 14개 일치 테스트는 실제 피해예방 효과의 증거가 아님.

## 심사위원 반례 질문과 대응

**질문:** 정상 은행 상담원이 정당한 이체 절차를 안내할 때도 멈추게 하면 오탐 아닌가?

**답:** 맞다. 위험 행동의 일시적 보류와 사기 범죄의 판정은 구별된다. 사기 여부를 단정하지 않고, 공식 경로 재확인을 우선하도록 한다. 정상 금융업무의 방해 비용도 독립 평가 대상이다.

**질문:** Zoro-1을 실제로 썼는가?

**답:** 본 시연의 합성 정책 루프에는 현재 연결되지 않았다. 실제 모델 호출 결과와 모델 체크포인트가 확보되기 전까지 사용했다고 말하지 않는다.

**질문:** 99개 테스트가 통과하면 보이스피싱을 예방할 수 있다는 뜻인가?

**답:** 아니다. 자동화 테스트는 코드 계약을 검증한다. 검증 데이터의 일반화 성능과 사용자 실제 피해 예방 효과는 독립 평가를 필요로 한다.

## 팀 표기

- **팀장:** 최한길(석사)
- **팀원:** 손호성·이진명(서강대학교 가상융합전문대학원 박사과정)
- 담당 역할, 개인별 신청 완료 및 공동 IP 사항은 실제 합의·증거로 확인한다.

## 금지된 홍보 문구

'100% 사기 탐지', '피해 차단 완료', '은행 계좌 동결', '실시간 딥보이스 분석 완료', 'Zoro 기반 실제 사기 확률 99%', '검증된 1초 미만 지연'은 실측/권한 증거 없이 사용하지 않는다. 모든 UI에서 `FIXTURE / SIMULATED`를 유지한다.


## 지급 요청 보호 데모: PAYLOCK 영역

- **0~20초:** 기존 의심계의 가치(위험 행동을 하기 전에 멈추고 확인)를 기업 지급 승인 업무로 연결해 설명한다.
- **20~55초:** 대금 8천만원(가상) 합성 청구서를 선택한다. 등록된 계좌와 일치하면 `READY_FOR_INTERNAL_REVIEW_NOT_PAYMENT`; 지급 완료가 아니다.
- **55~100초:** 같은 청구서의 계좌를 바꿔 제출한다. 메일 본문에 '승인 완료'가 있어도 `HOLD_FOR_INDEPENDENT_VERIFICATION`으로 보류한다.
- **100~140초:** 원래 주소록의 등록된 연락처로 별도 확인하도록 안내한다. 다른 reviewer ID를 입력해 모의 확인 결과를 기록한다. 단, 이름은 인증되지 않았으며 화면에 실제 지급 없음이 표시된다.
- **140~180초:** 6개 작성자 합성 사례에서 계좌 대조와 압박 어휘의 차이를 보이고, 모델을 선택했다가 미연결이면 안전하게 보류되는 장면을 시연한다. 'AI의 성능이 증명됐다'고 말하지 않는다.

심사위원 질문 예상: '왜 단순 if 문이 아니라 Zoro-1인가?' — **현재는 단순 대조의 유효성을 먼저 확보했고, Zoro-1의 비정형 문맥상 추가 이점은 아직 독립 시험으로 입증되지 않았다**고 답한다. 모델의 미래 실험 설계는 PRD-40 참조.
