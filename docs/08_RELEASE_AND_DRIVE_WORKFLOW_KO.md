# 현행 릴리스 출고·다운로드·외부 원천 참조 계약

## 사용자 승인 경계

- **Google Drive는 읽기 전용 참고 자료이다.** 사용자가 별도로 명시적인 새로운 쓰기 요청을 하지 않는 한 폴더 생성, 업로드, 이동, 이름 변경, 삭제, 동기화를 실행하지 않는다.
- 드라이브 소스를 참조해야 하는 경우 파일 메타데이터 조회, 본문 읽기, 실제 실행 검증을 구별해 기록한다. 원격 파일을 읽지 않았는데 읽었다고 주장하지 않는다.
- 해커톤 산출물의 전달은 **현재 채팅에서 검증된 파일을 직접 다운로드**하는 방식으로 한다.

## 릴리스 체크

1. 현재 기준 ZIP과 최상위 `all.md`, 내부 `VERSION_LEDGER.md`, 명세, 소스, 테스트를 실제 읽는다.
2. PRD↔System Prompt↔API↔코드↔테스트↔실제 관찰 증거의 양방향 정합성을 확인한다.
3. 실행 환경, 테스트 모드, 성공/실패/건너뛰기, 재현 명령을 기록한다.
4. `dmsg.skill`·`dmsg.zip` 두 컨테이너는 동일하고 그 안의 단일 `dmsg/SKILL.md`는 현행 사양과 일치해야 한다.
5. 패키지 최상위 `all.md`는 NotebookLM 활용을 위해 실제 현행 구현·제품 맥락·미검증·영상 설명을 충분히 담는다.
6. 버전 간 변경사항은 **오직 `internal/VERSION_LEDGER.md`**에 기록한다. 일반 문서는 현재 상태로 작성한다.
7. ZIP·파일 매니페스트의 SHA-256과 파일 크기를 검사하고 ZIP CRC와 전체 트리 일치 여부를 재확인한다.
8. 실제 파일이 존재할 때만 `sandbox:` 링크를 제공한다. Google Drive 업로드 수행 여부와 상관없이 원격 동기화 성공을 주장하지 않는다.

## 실세계 한계

- 작성자가 만든 테스트의 통과는 실제 보이스피싱 분류 정확도를 증명하지 않는다.
- 실제 Zoro 체크포인트 서빙/오프라인 구동/현장 기기 UX 검사는 별도 증거가 필요하다.
- 사용자 동의 없는 개인정보 저장·원격 모델 전송을 허용하지 않는다.
