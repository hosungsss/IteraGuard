## 실제 응답과 검증 방법
앞서 공개 서비스에서 받은 서로 다른 12건 및 이번에 새로 실제 입력한 8건, 총 20건의 응답에 로컬 보정 함수를 재실행했다. 공개 응답 원문 점수와 행동을 보존했다. 이는 실제 공개 응답의 로컬 재처리이지 수정본 배포 후 Zoro 재추론 성공이 아니다. 서비스의 모델 체크포인트 신원은 미인증이며 공개 서버와 로컬 코드는 동일성이 독립 확인되지 않았다.

- 원격접속 예방 경고: red/원격접속 → gray/현재 민감 행동 요구 없음.
- 과거 인증번호 요구 거절·신고 보고: gray/인증번호 전달 → gray/현재 민감 행동 요구 없음.
- 모호한 현재 요구: green/unknown → gray/unknown.
- 새 예방 문장: red/앱 설치 → gray/현재 민감 행동 요구 없음.
- 새 과거 신고 보고: gray/신고 요청 → gray/현재 민감 행동 요구 없음.
- 기존/신규 직접 인증번호 요구, 계좌변경 송금, 원격접속 및 혼합 설치·송금 요구의 빨강 결과를 모두 유지했다.
- 기존 일반 회비와 완료 보고, 신규 휴관 안내의 결과는 유지됐다.

## 남은 문제
새 구어체 반례 “금융회사 직원이라도 원격 연결은 승인하면 안 돼요.”는 범위를 제한한 문법 밖이다. 모델의 green/원격접속 요구를 gray/원격접속 추정으로 바꾸고 불일치를 설명하지만 행동 자체는 여전히 오분류다. 이 새 실패를 해결됐다고 집계하지 않는다. 범위를 임의 확장해 위험 해제를 늘리는 대신 별도 발화유형 모델 또는 검증된 문법 확대 후보가 필요하다.

가족 사칭·통화 불가·긴급 송금 사례의 gray/send_payment도 그대로다. 이번 범위는 문맥과 모순 보완이며 위험 수준 재보정까지 완성한 것이 아니다. 전체 오판 해결·모델 정확도 향상·실제 사기 판별률을 주장하지 않는다. 예방 문장의 gray는 보수적 정합성 보류이며 green 정답 복원으로 계산하지 않는다.
