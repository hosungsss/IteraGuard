# 역사 원문 보존

이 폴더는 현재 명세가 아니다. 각 파일의 원본 출처·바이트 수·SHA-256은 PROVENANCE.json에 기록했다. 기존 파일 내용은 수정하지 않고 복사했다.

- VERSION_LEDGER_through_v47_original.md: v3.1.0~v4.7 상세 변경 원장.
- CHANGELOG_v49_original.md: v4.9 FULL 안의 v4.8→v4.9 변경 기록. 동일 내용인 dmsg 참조 사본은 중복 독립 근거로 세지 않는다.
- v50_before_organization_*: 검증된 최초 v5 배포본의 문서. 이번 정리 전 기록을 보존한다.

v4.9 FULL에도 internal/VERSION_LEDGER.md는 없었다. 누락된 v4.8·v4.9 원장을 새로 발견한 것처럼 주장하지 않는다. 현재 사실은 루트 CURRENT_PROJECT_STATE.md와 docs/PRD_v50.md를, 새 상세 변경 기록은 internal/VERSION_LEDGER.md를 따른다.
