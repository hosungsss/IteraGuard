의심계 v4.4 — macOS 데스크톱 앱

실행
1. 압축을 풉니다.
2. "의심계 실행.command"를 마우스 오른쪽 버튼으로 클릭 → 열기 → 열기.
   (인터넷에서 받은 서명되지 않은 파일이라 처음 한 번은 이렇게 열어야 합니다.)
3. 기본 브라우저에 앱이 열립니다. 터미널 창을 닫으면 앱이 종료됩니다.

"손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서:
  xattr -dr com.apple.quarantine <압축 푼 폴더>
그 다음 다시 열어 주세요.

Apple Silicon(M1 이후)은 macos-arm64, 인텔 Mac은 macos-x64 묶음을 사용하세요.

모델 연결(선택): 로컬 kev 서버를 띄운 뒤 앱의 "모델" 탭에서 http://127.0.0.1:8008/v1/systemone 을 저장합니다.
이 앱은 Apple Developer ID 서명·공증이 되어 있지 않으며, macOS 실제 기기 실행은 개발 환경에서 검증되지 않았습니다.
