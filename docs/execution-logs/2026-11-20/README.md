각 JSON에는 실행 체크, 요청 ID·버전·업무 상태, Arena의 증거 내보내기, 모델 응답 지문이 들어 있습니다. 합성 입력은 SHA-256으로 기록했습니다. 공개된 세 로그의 유효한 Arena 판단 7건을 모델 응답 지문과 대조했습니다. B의 별도 신호등 검증에는 모델 응답 3건이 추가로 사용됐습니다.

C에서는 테스트 전용 로컬 전달 연결만 닫았습니다. 로컬 Zoro 서비스는 요청을 받을 수 있는 상태였고, 같은 전달 연결을 재개해 다음 요청이 모델까지 도달하는지 확인했습니다.

## C · 복구 안내 화면 재검증

기준 소스 `778eed8`에 복구 안내를 수정한 뒤 실제 로컬 Zoro로 `/arena`를 다시 시연했습니다. 장애 중에는 재시도 방법과 기존 요청의 실행 보류를 함께 안내합니다. 연결을 복구하고 같은 문장을 다시 제출하면 **분석 복구 완료**와 **이전 요청 · 확인 대기**가 각각 표시됩니다. 장애 중 미해결 2건에서 복구 후 1건으로 줄었으며, 같은 송금 확인 업무 ID가 계속 열려 있었습니다. [브라우저와 Arena 재실행 JSON](C_transport_failure_recovery_ui.json)

모델 실행 출처 표기는 `LOCAL_HTTP_MODEL_UNATTESTED`입니다. 응답 해시는 관측된 응답의 대조에 사용합니다. 세 로그의 결과 범위는 이 합성 시연과 이 환경입니다.
