## 원인과 수정
상태 안내 두 문단이 main 그리드의 직접 자식으로 삽입되어 고정 행을 사용하는 판단 과정 패널과 충돌했다. 안내 영역을 그리드 밖으로 분리했다. 데스크톱에서 입력과 판단 과정의 시작 위치를 맞추고, 작은 화면에서는 단일 열로 표시한다. 열의 최소 너비와 버튼 줄바꿈을 보완했다.

540px 이하에서는 장식 구체를 숨겨 제목과 입력 공간을 확보하고 입력 글자 크기를 16px로 유지한다. 동작 줄이기 설정에서 크기 변경 후 캔버스가 지워지는 현상을 수정했다. 숨긴 캔버스에서 음수 반지름 오류가 발생한 중간 검사 실패도 발견하여, 표시 영역이 없는 경우 그리기를 중단하도록 수정한 뒤 전체 브라우저 검사를 다시 통과했다.

기존 네이티브 입력창을 유지한다. 직접 타이핑과 Ctrl+V 붙여넣기를 실제 브라우저로 확인했다. Ctrl+Enter 판단 단축키도 검증했다. 합성 문장으로만 시험했다.

## 검증 결과
- Windows Edge headless: 1440, 1024, 900, 768, 390, 320px 모두 가로 넘침 없음, 페이지 자바스크립트 오류 없음.
- 1440px: 입력 패널과 판단 과정 패널 시작 y=531.203125px로 일치.
- 1440/390px: 예제 4종, 직접 입력, 브라우저 클립보드 붙여넣기, 판단 버튼/단축키, 사람 검토 토글, 업무 선택 및 UNRESOLVED 관찰, 기록 새로고침, 증거 내보내기/파일 다운로드, 세션 보관/재개/신규/과거 조회, 패널 닫기/Escape/배경 클릭 통과.
- Python tests_v59 15건 및 Node UI/복구 38건 통과. 최종 캔버스 가드 추가 후 브라우저 검사 재통과.
- 증거: results.json, layout-{width}.png, after-actions-1440.png, after-actions-390.png. comparison.html에서 수정 전후를 비교할 수 있다.

## 검증 범위와 남은 사항
실제 Edge 엔진이지만 모바일은 화면 너비 에뮬레이션이다. 실제 휴대폰, Safari, Firefox, 모든 관찰값 조합은 검증하지 않았다. 모델 응답은 CONTROLLED_FIXTURE_NOT_ZORO이며 실제 Zoro 추론 성공을 의미하지 않는다. 화면의 모델 미설정 안내를 숨기지 않았다. 공개 사이트의 로그인 이후 경로와 배포 반영은 이번 로컬 검사로 확인되지 않았다. 로컬 검사 후 사용자가 커밋·푸시·공개 사이트 반영을 승인했다. GitHub 반영을 진행하며, 공개 사이트는 연결된 Sites 계정의 소유/편집 목록에 없어 배포 접근 확인이 필요하다. GitHub CI는 테스트만 수행하며 사이트 배포 작업은 없다.
