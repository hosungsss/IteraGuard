# 심사 전문 관점별 증거 안내

첨부 페르소나는 전문 질문의 가설이며 실제 개인 선호·배점을 추정하지 않는다. 팀 리더는 최한길이다.

| 관점 | 질문 | 보여줄 자료 | 미완료 |
|---|---|---|---|
| 모델·데이터 | 실제 어떤 모델이 판단했는가 | 시나리오 JSON의 provenance, current_turn_action/reason, 소스·응답 지문 | checkpoint/head/revision 독립 인증 |
| 시스템 | 재현·실패 복구·지연 분모는 무엇인가 | README 명령, v56 로그, 출처별 server_pipeline_ms | 실제 브라우저 E2E·현장 장비 |
| 행동·상태 | 새 위험과 이전 위험을 함께 관리하는가 | open_tasks, prior_pause, 보고 전후 재조회 | 외부 독립 확인·위험 해제 |

5분 발표 초안: 사용자 문제 40초, 결정→업무 구조 55초, 위험·기억·실패 복구 140초, 검증과 제한 35초, 적용가치 30초. 현장 공식 Google Slides 템플릿을 별도로 사용해야 하며 이 문서/DOCX가 공식 발표 제출물을 대신하지 않는다.

원문 공식 PDF·발표 순번·제출 링크·GitHub 접근·라이선스 범위는 최종 제출 전에 확인한다. 도구는 외부 초대·업로드·메시지를 보내지 않았다. NPU 이식과 새 모델 재학습보다 현장 실호출 및 복구 리허설을 먼저 완료한다.
