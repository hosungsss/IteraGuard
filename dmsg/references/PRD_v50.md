# v5.0 제품 계약

주력 흐름은 현재 합성 문장 → 실제 Typed 판단 → 사용자 확인 업무 → 자기보고 관측 → 새 문장 재판단이다. 범위는 로컬 프로토타입 개발 후보다.

정책 행동은 NO_STRONG_SIGNAL, CAUTION, PAUSE_AND_VERIFY, ASK_HUMAN 네 가지다. NO_STRONG_SIGNAL은 안전 인증이 아니다. 기본 legacy는 기존 임계 0.70을 보존하고 DRA는 비교 경로다. 정상 송금 요청과 정상 정보의 과개입은 해결되지 않았다. 388회 개발 비교에서 세 단독 질문 후보가 새 회귀를 보여 원본 7문항을 유지했다.

현재 턴 advisory, 세션 prior_pause, 확인 작업 상태를 분리한다. 모델은 현재 문장만 읽고 서버가 과거 위험을 결합한다. 작업 완료 자기보고는 위험 해제가 아니다. CLOSED_UNRESOLVED는 미해결 상태로 화면 작업을 종료하는 명시 동작이며 OPEN으로 재개해도 과거 위험이 유지된다. 종료된 세션의 새 추론은 거부한다. 요청 ID와 버전으로 중복/지연 반영을 막는다.

새 AI 25개는 개발 합성 데이터다. 독립 사람 주석/잠금 평가와 Android 실기기는 별도 게이트다. L2 본문/G7/기관 질문/L1 항목은 현행 유지다. PAYLOCK·LinkGuard/APK·도메인·메모리 기존 기능과 경계는 보존한다.
