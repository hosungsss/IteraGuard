# 네 가지 출품작 후보의 선택과 변경 승인 게이트

**현재 상태: 결정 전.** 두 명이 선택하도록 제작한 TeX 기반 공동 선택서 v2.0은 제품 결정의 참고 문서이지만, 작성·제작만으로 합의가 완료된 것은 아니다. 기존 의심계의 구현은 그대로 유지한다.

| 후보 | 실제 사용자와 사용 시점 | 필요한 독립적 추가 가치 | 기술·운영상 최소 수용 조건 |
|---|---|---|---|
| PAYLOCK | 기업 재무담당자, 지급 승인 직전 | 단순 계좌 불일치 규칙을 넘는 비정형 요청 화행 판단 | 실제 송금 연결 금지·합성 계좌·승인된 연락처 별도 확인 |
| STOPLINE | 정비담당자·안전관리자, 재가동 보고 직전 | 비정형 작업 기록의 누락·충돌 탐지 | 법정 작업허가·LOTO 대체 금지, 실제 설비 제어 금지 |
| LEAKLESS | 기업 IT·보안팀, 문서 공유/업무 도구 실행 직전 | 공유를 무조건 거부하지 않고 목적을 달성하는 안전한 대안 제시 | 합성 문서, RBAC/ABAC 외부 정책, 유출 금지 테스트 |
| 의심계 | 통화·메시지의 잠재적 피해자, 위험행동 직전 | 위험 화행 인식과 정상 대화 오탐 감소 | 실모델 계약, 독립 주석셋, 개인정보 미수집 기본 |

**변경 승인 조건:** 현재 사용자 지시에 따라 의심계를 기본 제품으로 유지하면서 PAYLOCK을 제한된 지급 요청 검토 모듈로 포함한다. 팀의 독립 서면 승인이나 권한 귀속을 추정하지 않는다. 후보 전환 확정 시 `새 고객의 안전 위험 + 실제 데이터 흐름 + 모델 질문 + UX + 실행 권한 + 테스트 + 발표`를 독립적으로 재설계한다. 기존 의심계 자산은 내부 릴리스 장부와 원본 패키지로 보존하며, 코드 재사용률을 미측정 추정치로 발표하지 않는다.

**결정 방식:** 두 참여자가 독립적으로 선택 → 합의 결과를 서명·기록 → 신규 세 안 가운데 공동 선택이 없으면 현행 의심계를 계속한다. 합의가 없는 상태에서 소프트웨어가 자동으로 새 방향으로 바뀌었다고 표현하지 않는다.
