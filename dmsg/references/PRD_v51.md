# v5.1 제품 계약

주력 흐름은 현재 합성 문장 → 실제 Zoro-1 Typed → 현재 턴 안내 → 사용자 확인 업무 → 자기보고 관측 → 새 문장 재판단이다. 제품은 로컬 개발 후보이며 실제 발신자·기관·계좌를 인증하지 않는다.

정책 행동은 NO_STRONG_SIGNAL, CAUTION, PAUSE_AND_VERIFY, ASK_HUMAN 네 가지다. 요청 없음·목록 밖 요청·민감 요청·불분명함을 분리하며, 요청이 구체적이라는 사실을 무해함으로 취급하지 않는다. 민감정보/원격 접근과 비정상 송금 단서는 현재 화자의 요구와 원문 단서가 함께 충족될 때 판단에 사용한다. 기존 임계값0.70과 기준선 PAUSE 보존 경계를 유지한다.

현재 Typed 입력은 profile·policy·질문 순서/지문을 요청 전에 고정한다. v50-baseline, evidence-legacy, semantic-candidate, specific-candidate를 명시적으로 구분한다. 새 필수 문항이 없거나 요청 binding이 다르면 평가를 거부한다. DRA는 원본 기준선 profile과만 조합한다. 현재 제품 선택은 release_selection과 실행 manifest가 정본이며 registry compatibility default가 아니다.

현재 턴 advisory, 세션 prior_pause, 확인 작업 상태를 분리한다. 모델은 현재 문장만 읽고 서버가 과거 위험을 결합한다. 작업 완료 자기보고는 위험 해제가 아니다. CLOSED_UNRESOLVED 종료/OPEN 재개에도 과거 위험은 유지된다. 종료 세션의 새 추론은 거부하며 요청 ID/버전으로 중복·지연 반영을 막는다. PC 단문 앱은 세션 위험을 합치지 않는다.

근거 표시에는 가능한 경우 행동·대상·요구가 들어 있는 원문 절을 사용한다. 원본 앵커는 메모리에서 보존하고 표시용 근거를 분리한다. 어미 단독이나 경고/인용 범위가 모호한 구간을 확정 위험 근거로 표시하지 않는다. 의미 구간을 찾지 못하면 확인 불가를 표시한다. 문자 offset 일치, 표시 coverage, 의미 적절성을 별도로 검증한다.

수용 조건은 불필요 정상 ASK 감소와 필수중단 누락 감소를 함께 확인하고, 새 위험/맥락부족 정상처리·정상 PAUSE·기존 허용 안내 손실이 생기지 않는 것이다. 기존98와 AI 개발36은 개발/회귀 자료다. family를 분리한 AI24의 잠금 검증도 사람 독립 평가가 아니다. 사람 작성·독립 주석과 Android 실기기 검증은 별도 NOT_RUN 게이트다. 수치·실패·범위는 구현 보고와 현재 상태를 따른다.

PAYLOCK·LinkGuard/APK·도메인·메모리 기능은 기존 경계를 보존한다. 실제 은행 제어·기관 연락·외부 평판 조회·자동 위험 해제·새 reasoning LLM은 범위 밖이다. L2 본문/G7/기관 질문/L1은 승인 전 현행 유지다.
