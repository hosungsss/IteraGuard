## 로컬 Arena에서 551건 재측정

로컬 Zoro가 연결된 환경에서 원본 CSV 파일을 지정해 Arena를 실행한다. 위 원본 링크의 고정 리비전에서 `test.csv` 원본 바이트를 사용한다.

```bash
python -X utf8 -m arena.server --port 8769 --signal-benchmark-csv /path/to/test.csv
```

브라우저에서 `http://127.0.0.1:8769/`를 열고 **성능검증 → 재측정**을 누른다. Arena에서 설정한 신호등 질문 프로필로 원문을 로컬 모델에 한 건씩 보내고, 채점에는 표시 등급과 CSV의 정답 라벨을 사용한다. 기본 프로필은 `high-recall`이며 이전 프로필을 쓰려면 예를 들어 `--signal-profile baseline`을 지정한다. 진행 건수가 표시되고 551건을 끝내면 수치와 색별 건수를 함께 갱신한다. 프로세스마다 한 번에 한 작업을 실행한다.

| 지표 | 계산 |
| --- | --- |
| 이진 정확도 | 정상 중 초록·회색과 피싱 중 주황·빨강의 합 ÷ 551 |
| 피싱 탐지율 | 피싱 중 주황·빨강 ÷ 50 |
| 정상 탐지율 | 정상 중 초록·회색 ÷ 501 |

회색은 판단 보류다. 이진 정확도와 정상 탐지율은 경보 여부를 집계하므로 회색을 비경보로 계산한다. 엄격 일치율에서 정답으로 세는 정상 문자는 초록만 해당한다.

CSV 지문이나 모델 응답에 문제가 생기면 해당 실행을 중단하고 마지막 완료 결과를 계속 표시한다. 완료 결과와 실행 상태는 Arena 프로세스 메모리에 보관한다. 프로세스를 다시 시작하면 화면은 저장된 기준 집계를 표시한다. 공개 시연 화면에서는 저장 결과와 CSV 지문 확인을 제공한다.
