# v5.1 구현·실험·디버깅 기록

기준일: 2026-11-04 KST. v5.1은 **판단 품질을 실제로 개선한 개발 후보**다. 독립 사람 평가와 실기기 검증을 마친 최종 제출본은 아니다. 최종 ZIP 해시·신규 소스 수·독립 추출·최신 포인터 검증은 [외부 배포 영수증](IMPLEMENTATION_RECEIPT.json)이 정본이다.

## 이번에 달라진 동작

기존 v5의 실행 기반만 고치는 데서 나아가, 현재 요청의 범위·현재 민감정보/원격 요구·송금의 비정상 조건·요구 행동의 명시 여부를 추가로 질문한다. 기존 7문항을 보존한 별도 11문항 profile을 기본 legacy 경로에 연결하고, 모델 응답과 원문 단서를 결합하는 버전별 해석 정책을 Python/JS에 구현했다. 정상적인 준비물·방문 요청을 `none+direct_request`라는 이유만으로 일괄 보류하던 문제와, 경고 뒤 새 민감 요구를 놓치던 일부 사례를 개선했다.

질문 profile·정책·질문 hash를 요청 전에 묶고 응답에서 확인한다. 새 필드가 없거나 계약/연결이 실패하면 보류하며 다른 모델로 조용히 대체하지 않는다. DRA는 기존 7문항 별도 조합이다. 가중치 재학습·임계치 인하·확률 보정은 하지 않았다. 기존 세션 위험 보존·종료/재개·사용자 확인 보고의 경계는 유지했다.

근거는 행동과 대상이 있는 절의 원문 범위로 확장하고 찾지 못하면 확인 불가를 표시한다. 표시용 맥락과 실제 정책의 원래 근거 trace를 분리했으며, 표시 모듈은 판정을 바꾸지 않는다. 별도 reasoning LLM이나 새 middleware 서버는 도입하지 않았다. 현재 공통 실행 모듈 안에 해석 계층을 추가한 것으로, 별도 서버가 반드시 필요하다는 증거는 없다.

## 실패를 숨기지 않은 개발 과정

evidence 문구만 바꾼 7문항 후보는 기대 안내 3개를 개선했지만 필수중단은 개선하지 못해 최종안으로 삼지 않았다. 10문항 후보와 절 범위 해석을 실험한 뒤, 11번째 요구 명시 문항을 추가했다. semantic policy /3에서는 배송 주소 변경 요청(V13)을 평범한 요청으로 잘못 풀어주는 신규 회귀를 발견해 HOLD했다. 요청이 명시됐다는 답을 평범한 요청이라는 증거로 넘겨짚은 분기를 /4에서 제한하고, 간접 이동 단서를 막은 뒤 기존 데이터로 재생해 회귀 제거를 확인했다. /3 실패 출력도 패키지에 그대로 남겼다.

잠금 검증 뒤 발견한 수정은 `arena.manifest()`의 계약 읽기 TypeError를 정적503으로 반환하게 한 예외 처리뿐이다. 판단 규칙·질문·가중치·임계치는 바뀌지 않았다. 잠금 당시 코드 사본과 수정 영수증을 각각 보존했다.

## 남은 문제

근거 표시 후보절163개 중52개(31.9%)를 표시했고111개는 확인 불가였다. 표시가 있는 문장은157개 중48개다. 표시52개 좌표와 원문 인용은 모두 유효하지만 이 수치가 의미 적절성을 인증하지는 않는다. AI 주석과의 겹침도 낮고 절 확장에 따른 과도한 강조 가능성이 남는다. 독립 사람 의미 평가는 NOT_RUN이다.

## 최종 배포 확정

FULL은 137,162,354바이트·764파일이며 SHA-256은 `72a59c5d9399a7c80e9b228c1defb992f9a1ea83465d84c12675e0a045d3624f`다. 독립 추출본의 파일764개와 manifest763항목, 생성물/배포 검사6개가 통과했다. 최초 검증기의 경로 실패는 의도적 공격 시험 APK였다. 기존 v5.0 해시·CORPUS 선언·A06·내부 전체 멤버 해시가 일치한 표본만 메모리에서 읽었고 내부 경로를 추출하거나 실행하지 않았다. 최초 실패 영수증과 수정한 검증기를 verification/attempt1_unsafe_fixture에 보존했다. 실제 FULL과 배포APK의 경로 규칙은 완화하지 않았다.

검증 후 모음/워크스페이스 LATEST_VERSION.json을 모두5.1 개발 후보로 전환하고 경로·ZIP 해시를 다시 대조했다. 소스·질문·판단 규칙·APK·FULL은 독립 검증 이후 변경하지 않았다. 기존5.0의 manifest485파일과 FULL 해시도 재확인했다.
