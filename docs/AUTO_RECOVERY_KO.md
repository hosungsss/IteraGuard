# 실행 중 자동 복구

main 05103c7의 문맥별 합성 UI와 통합한 PR 후보. 커밋·푸시는 사용자 승인 범위이며, main 병합 및 사이트 배포는 별도다.

## 동작

- 네트워크 실패·요청 시간 초과·429 혼잡·JSON 오류 응답인 502/504에서 복구 가능 여부를 판단한다.
- 읽기 요청은 최대 2회 추가 시도한다. 각 요청의 기존 70초 제한을 유지한다.
- 판단 POST는 원본 입력·세션·버전·요청 ID를 고정한다. 0.4초/0.8초 대기 후 저장 상태부터 조회한다.
- 같은 요청이 저장되어 있고 세션 버전이 일치하면 기존 결과를 반환한다. 새 추론을 수행하지 않는다.
- 저장 결과가 없고 세션이 같은 버전으로 열려 있을 때만 원래 요청을 다시 보낸다. 서버의 기존 멱등성 검사를 이용한다.
- 세션이 변경되거나 상태 조회에 실패하면 즉시 중단한다. 복구 횟수와 결과를 화면의 복구 상태 영역에 표시한다.

## 자동으로 바꾸지 않는 것

인증·권한, 정책/스키마 위반, JSON 파싱 오류, 불명확한 모델 판단, MODEL_NOT_CONFIGURED, 계약 실패는 자동 수정하지 않는다. 정상 HTTP 응답으로 반환된 ASK_HUMAN은 복구 대상 오류가 아니다. 새로운 세션 생성 및 종료/재개 요청을 자동 재전송하지 않는다. 원문이나 확률, 이전 위험, 정책을 임의로 바꾸지 않는다.

실행 중 소스 코드를 LLM이 작성·배포하는 기능이 아니라, 검증 가능한 범위의 통신/상태 복구 기능이다. 모델 서버를 자동 설치·기동하거나 가중치 정체를 검증하는 기능은 포함하지 않는다. 브라우저 종료 후 진행 중 복구를 이어가는 영속 작업 큐도 아니다.

## 검증

새 복구 테스트: 응답 유실 후 저장 결과 복원, 동일 payload 재시도, 세션 변경 중단, 재시도 상한, 인증 실패 중단, 정상 판단 보류 보존, 세션 생성 중복 방지. 기존 오류 안내 및 UI와 합쳐 Node 37개 통과. mock 네트워크/최소 DOM 시험이며 실제 Zoro·공개 사이트 인증 후·휴대폰에서 실행한 결과는 아니다.

실행: `node --test tests_demo_validation/*.js tests_v50/test_session_ui.js tests_v53/test_choice_ui.js`.
화면에서 70초를 초과해 취소해도 서버 처리는 완료될 수 있으므로, 저장 상태를 확인하지 못하면 추측해서 재전송하지 않는다. 중계 서버가 502/504를 HTML로 반환할 경우 자동 복구하지 않고 형식 오류로 중단하는 보수적 동작이다.
