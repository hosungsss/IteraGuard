의심계 v4.4 — Windows 데스크톱 앱 (64비트)

실행
1. 압축을 풉니다(압축 파일 안에서 바로 실행하지 마세요).
2. run-dmsg.bat 또는 dmsg-desktop.exe를 더블클릭합니다.
3. "Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행. (코드 서명 인증서가 없는 앱이라 표시됩니다.)
4. 기본 브라우저에 앱이 열립니다. 검은 콘솔 창을 닫으면 앱이 종료됩니다.

모델 연결(선택): 로컬 kev 서버를 띄운 뒤 앱의 "모델" 탭에서 http://127.0.0.1:8008/v1/systemone 을 저장합니다.
Windows 실제 기기 실행은 개발 환경에서 검증되지 않았습니다.
