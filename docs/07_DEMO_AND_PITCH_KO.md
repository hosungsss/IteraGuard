# 의심계 Arena 시연 안내

시연 첫 화면은 run_hackathon.ps1로 실행한 Arena다. 한 문장을 분류하는 장면에 이어 확인 업무와 남은 위험을 보여준다.

1. 모델 출처 상태와 합성 입력임을 먼저 밝힌다. 실제 서버가 없으면 연결 실패 화면과 저장 증거를 구분한다.
2. 합성 민감정보 요청을 넣고 현재 행동·사유·확인 업무를 보여준다. 결과는 실제 응답에 따라 설명하고 기대 결과를 연출하지 않는다.
3. 사용자 확인 보고를 저장하되 이전 위험이 해제되지 않는다는 점을 설명한다.
4. 모호한 새 요청의 후속 업무가 생성되는 경로는 통제 응답 회귀 증거와 함께 설명한다.
5. 미해결 보관과 재개를 보여준다. 닫기가 안전 판정이 아님을 밝힌다.

핵심 설명: “의심계는 모델의 현재 요청 해석을 확인 가능한 다음 행동으로 연결합니다. 응답을 받았다는 사실, 사용자가 확인했다고 보고한 사실, 기관에서 검증된 사실을 구분합니다.”

저장 AI24의 어휘 보완 결과와 독립 정확도를 혼동하지 않는다. 근거 구간 일치율을 전체 정확도로 제시하지 않는다. 실모델 신원·신규 추론·독립 인간 평가는 이번 패키지 검증에 포함되지 않았다.
